# 90—120秒演示脚本（可选视频未录制）

0—15秒：介绍个人宏观研究者找历史可比案例、核对时间和走势的任务。展示统一时间轴上的49个部分样本节点与双资产。

15—35秒：选默认消费与工业价格对照事件；打开来源，说明原卡引用待复核、次日报价起点。勾选确认。

35—55秒：查看先前联合发布与单项指标卡，指出口径差异；在时间轴切换PPI或LPR事件，事实、案例和走势联动；不看事后涨跌选例。

55—80秒：上证/黄金切换，5/20条窗口，指出基准、实际终点和未知状态；人民币Au9999，非美元金。

80—110秒：组装预研与计算解读，说明离线AI无实时模型调用；个人修订后保存/导出。结尾指出历史同窗不证明因果、缺预期差不编造。
