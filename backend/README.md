# Backend 工具目录

本目录收纳离线事件资料整理、候选导出、数据校验与本地预览脚本，以及用户提供的候选池筛选 skill。

当前参赛版没有在线后端服务或 API。网页由 `frontend/` 静态托管，确定性行情窗口计算也在浏览器内执行。

## 常用命令

- `npm start`：启动本地静态预览，默认地址为 `http://127.0.0.1:18791`。
- `npm run build`：检查前端静态文件和演示数据范围。
- `npm run build:demo`：用固定种子重建构造行情与示范研究报告。
- 离线候选整理脚本需要 `REPLAY_SNAPSHOT_DIR` 指向本机有权使用的事件资料；源资料不随仓库分发。
