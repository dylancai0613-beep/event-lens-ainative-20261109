# 客户端差异与交付

这是一份通用Skill源目录，不包含客户端专属调用代码、登录、Key或安装路径。

- Codex：由用户按本机支持的Skill机制安装或显式提供本目录；使用当前会话实际可用的文件/脚本/来源工具。不要假定存在某个MCP工具，也不要自动把本目录装入个人skills。
- WorkBuddy：按该客户端当前支持的技能/知识文件机制加载SKILL.md及引用资源；先查看当前工具清单，再使用对应来源工具。不能照搬Codex工具名和路径。
- 两端都没有某来源权限时，只报告未覆盖；不从其他模块或用户配置中借凭据。脚本不可运行时保留“未机器校验”状态。

本轮项目内脚本、规则和Schema已用于离线试筛与校验；未在WorkBuddy或Codex重新加载为已安装Skill并完成真实来源检索。这两项需要后续客户端验收，不能以脚本通过替代。

网站和Skill从同一references/candidate-batch.schema.json读取版本规则。移动部署目录时须将skills与integration置于同级，不能只复制服务器文件而漏掉Skill契约。升级契约应新增版本并联动升级，不独立修改两份Schema。
