# 以事为镜 · Event Lens

面向个人宏观研究者的事件对照研究工具。同花顺笔试题14独立参赛版本，从复盘王提炼事件、证据与确定性计算的主链路。用户在统一时间轴选择自然标题的事件，再查看历史对照。货币政策、海外利率、通胀价格只是本次收集展示样本的方向，产品不限定三种事件或标题格式。上证指数和黄金只作为构造数据的示意主题，不包含任何真实行情。

## 产品入口与源码

- 产品：https://macro-event-replay-luna.opalescentdisco1.chatgpt.site （线上演示使用明确标注的构造行情数据，不代表真实市场表现。）
- GitHub仓库：https://github.com/dylancai0613-beep/event-lens-ainative-20261109 。

## 启动

Node.js 20+，零运行依赖，任意操作系统。

```sh
npm start
# http://127.0.0.1:18791
npm test
npm run build
npm run build:demo # 可复现地重建构造行情和演示报告
```

默认端口18791，可通过 `PORT` 环境变量修改。**无需任何行情或模型环境变量**。直接双击HTML会因本地文件fetch限制而失败，请使用HTTP服务器。也可以 `npx http-server dist`，这会按需下载该第三方工具；内置start无需下载。

`frontend/` 保存可编辑的浏览器应用和运行数据；`npm run build` 将它复制为 Sites 使用的静态部署目录 `dist/`。`backend/scripts/build-data.cjs`、`backend/scripts/expand-themes.cjs`和`backend/scripts/export-candidates.cjs`是离线事件整理工具，需要通过`REPLAY_SNAPSHOT_DIR`显式指向有权使用的本地事件资料；源资料不随仓库分发。运行数据生成脚本后执行`npm run build`更新部署副本。`npm run build:demo`可在无需源项目的情况下，以固定种子重建两条构造价格序列及示范报告并生成`dist/`。产品运行、测试和静态打包不依赖原服务器或API。`evidence/data-inventory.json`保留事件范围、生成样例数量和哈希。

## 评审的三分钟操作

1. 默认选“2026-09通胀数据发布：消费与工业价格对照”。打开来源，核对待复核状态和日期对齐约定，勾选确认。
2. 查看同含CPI/PPI的联合发布案例，以及仅含共同指标的补充对照；排除不合适的案例。
3. 切换上证指数/黄金示意、1/5/20个演示点，检查构造基准值、终点值和计算公式。
4. 组装解读，注意价格只是构造数据，填写个人修订并导出。
5. 在左侧时间轴点击另一件事，或按月份/文字检索。例如PPI单项发布、LPR调整、MLF操作；事实、历史案例和走势一并更新。没有合适案例时显示不足状态。

本版以精选事件完成研究功能演示，不提供新增事件、草稿或研究档案入口。顶部四步为可跳转导航，并随页面浏览位置更新高亮。

## 数据与时间口径

事件筛选范围固定为 **2023-11-09—2026-11-09**，包含49条候选（国内货币政策17、海外利率9、通胀价格23）。保留原库的自然标题，新增准备金率、再贷款、公开市场操作、PPI及消费与工业价格联合发布。它们是范围内的部分事件样本，不是新闻全量。每条保留来源、资料发布日期、事件日、首次公开日期与核实状态。原卡引用使用 `published_card_excerpt` 并保留旧卡ID；少量官方页面在本次重新打开。已知一条原链接404，显示待补证，不进入自动匹配。

**行情是构造演示数据。**原有上证与黄金历史行情公开再分发权未能核实，已从当前发布版本替换。上海黄金交易所的官方行情产品说明要求取得许可后传播交易信息；本版不随产品发布供应商行情。构造数据由 `backend/scripts/build-synthetic-market.cjs` 生成，共783个点/资产，使用固定种子，与真实市场和具体事件无关；日期轴只是周一至周五，并非交易所日历。SHA-256、生成方式和范围见 `evidence/data-inventory.json`。UI、报告和导出的JSON均标明其非真实行情，不可用于投资研究或绩效判断。

本产品采用保守日级演示：从记录的公告/事件日次一日起，从构造工作日序列取值；基准是起点前最后一个演示值。日期和值均为合成示例，不能体现美联储时区、真实市场休市或黄金交易时段。两条序列只用于演示同一计算函数。

演示变化为 `(终点值/基准值-1)*100%`。N为后续有效演示点数量。非法值、日期乱序、缺少基准、观察期不足或超过15个自然日的断层都不填结果。序列仅供确认程序按所选窗口定位、算值和显示缺失状态，不表示实际投资表现。

## AI使用、验证与候选人修正

### AI工具、参与环节与候选人修正

- **使用的工具：**GPT-6 Luna（Max）参与早期资料准备与界面修改；Codex参与需求/旧项目审阅、候选事件整理、相似案例规则与确定性计算、前端实现、文档和发布。用户提供的 `macro-event-candidate-pool` skill 用于离线筛选、分层和引用校验，它不是新闻数据源。网页运行时不调用在线大模型、行情或新闻API。曾对 iFinD MCP 发起无凭据初始化探测，收到401，未请求或取得任何金融数据。
- **候选人修正：**你指出三类主题不应成为产品硬分类，要求保留事件自然标题、时间轴选择和同类案例；删掉新增草稿、资料准备说明、离线样本标记和研究档案入口；将品牌改为“以事为镜”，并要求修正暗色界面和步骤导航。你也确认不接实时API，行情只能作为明确标注的构造演示，不能伪称真实表现。
- **人工复核发现的问题：**Codex复核Luna初稿时发现准备时间早于数据末日、LPR与结构性再贷款被当成同工具案例、未访问的来源链接被当作已核实等问题；据此调整案例、标记来源状态，并将404来源排除在自动匹配之外。详细过程见[AI使用与验证记录](docs/AI_USAGE.md)。

### AI角色及相对价值

使用用户提供的 `macro-event-candidate-pool` skill，离线完成宽筛分层、事实与解释区分、引用组织；候选JSON、可读清单与校验记录在evidence目录。匹配不使用标题格式：依据主体、地区、具体工具/指标、方向、阶段和日期约束入选；同一指标口径优先，共同指标与跨指标价格观察逐项说明差异；跨政策工具仅作为同主体同方向的关联线索，后续涨跌不用于选案例；宏观环境与预期差不足时标注未知。

**本版不接在线模型API**。Luna进行初步资料准备，额度用尽后由Codex接手，离线编写逐类差异/传导假设。网页把预研片段与本次选中案例的确定性计算结果组装成报告，并明确说明无在线模型调用。按钮不伪装成实时大模型生成。AI的增量价值在阅读材料、提炼结构、揭示对照局限和辅助形成可修改研究记录；规则只负责可核验计算和准入。当前演示不提供自定义材料录入。

没有实测节省时间、用户准确率或收益提升。验证计划：用同一研究任务比较人工找例耗时；由研究者逐对评价候选相关性；记录引用可追溯率、用户修改位置与缺口处理。历史测试记录不当作真实用户成果。

## 目录结构

```text
event-lens/
├── frontend/                  # 前端源文件、运行数据和随站点发布的资料副本
├── backend/
│   ├── README.md              # 离线工具说明；本版没有在线后端 API
│   ├── scripts/               # 离线数据整理、候选导出、校验和本地预览
│   └── skills/                # 候选池筛选 skill 与规则
├── dist/                      # npm run build 生成；Sites 部署目录
├── docs/                      # 提交文档主版本
├── evidence/                  # 候选数据和复核记录主版本
├── tests/                     # 确定性计算测试
├── package.json
└── .openai/hosting.json        # Sites 静态目录指向 dist/
```

计算引擎在浏览器中运行。`backend/` 只用于离线准备资料和本地预览，不提供线上服务。`dist/` 是由前端源目录复制生成的发布副本；Sites 只部署 `dist/`。`frontend/docs/` 与 `frontend/evidence/` 是随静态产品发布的精选副本；仓库根目录的 `docs/` 和 `evidence/` 是交付记录的主版本。

## 复用范围

新项目位于D盘独立目录；原复盘王只读。参考其事件字段、同工具同方向思路和窗口计算边界，本版本实现独立的静态计算模块。未复制原站认证、个人模型配置、完整数据库和付费附件。代码是否公开与数据许可是两个独立问题；本版仓库和网站不包含供应商行情。

界面采用深色、等宽编号与暖色强调，参考编辑器的简洁信息层次；没有引入额外运行依赖。
