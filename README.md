# 事件镜 · Event Lens

面向个人宏观研究者的事件对照研究工具。同花顺笔试题14独立参赛版本，从复盘王提炼事件、证据与确定性计算的主链路。三类样本：**中国货币政策（LPR）、美联储利率决议、中国CPI发布**；资产仅**上证指数000001.SH**与**上海黄金交易所Au9999（人民币元/克）**。

## 产品入口与源码

- 产品：https://macro-event-replay-luna.opalescentdisco1.chatgpt.site （实际发布状态见交付记录）
- GitHub仓库：https://github.com/dylancai0613-beep/event-lens-ainative-20261109 。
- 无登录、无需API Key。研究保存在当前浏览器；可导出JSON与HTML简报。

## 启动

Node.js 20+，零运行依赖，任意操作系统。

```sh
npm start
# http://127.0.0.1:18791
npm test
npm run build
```

默认端口18791，可通过 `PORT` 环境变量修改。**无需任何行情或模型环境变量**。直接双击HTML会因本地文件fetch限制而失败，请使用HTTP服务器。也可以 `npx http-server dist`，这会按需下载该第三方工具；内置start无需下载。

`dist/` 是可部署静态文件。`scripts/build-data.cjs`和`export-candidates.cjs`是一次性的离线资料准备工具，依赖原复盘王已发布快照路径及工作文件，单独克隆后不必执行。可直接替换 `dist/data.json` 中的获准快照并验证。网站运行、测试和打包均不依赖原服务器或工作目录。`evidence/data-inventory.json`保留本次快照范围、数量和哈希。

## 评审的三分钟操作

1. 默认选2024-10-21 LPR调整，打开来源、核对首次公开日期待核和日级对齐约定，勾选确认。
2. 比较2024-07-22与2024-02-20两个先前同工具、同方向案例；查看差异，可排除一个。
3. 切换上证/Au9999、1/5/20条报价窗口，检查实际基准和终点。
4. 组装解读，区分事实、代码计算、AI预研和待验证推断；填写个人修订，保存、刷新恢复或导出简报。
5. 切换美联储与CPI类别。选择较早事件或LPR维持不变，会真实显示同方向历史案例不足。

自定义材料为研究草稿：用户手填日期、主题、方向、事实摘录和来源。保持“用户提供，未独立核实”；不自动读取网址，不执行材料内指令，不发布到原复盘王。

## 数据与时间口径

事件筛选范围固定为 **2023-11-09—2026-11-09**，包含31条候选（LPR4、FOMC9、CPI18）。这是从已有发布索引筛选的部分样本并补充一个官方回顾节点，未全量抓取所有新闻、月份或2026年议息记录。每条保留来源、资料发布日期、事件日、首次公开日期与核实状态。原卡引用使用 `published_card_excerpt` 并保留旧卡ID；少量官方页面在本次重新打开。已知一条原链接404，显示待补证，不进入自动匹配。

上证725条报价截止2026-11-06；Au9999 718条报价截止2026-10-27。来自用户授权取用的复盘王已发布历史快照及服务器现存增量。没有调用iFinD或扶摇数据接口、没有触发服务器更新任务。服务器黄金更新状态quota_exhausted，应用明确披露。**这些资料不宣称开放数据许可**；供应商再分发许可未证明，当前只作用户授权的笔试研究演示，商业复用/进一步传播应换用已获许可的数据。未包含客户研究、数据库、原始付费报告、认证配置或密钥。

本产品采用保守日级观察：从记录的公告/事件日次一日开始取报价；基准是起点之前最后有效收盘。对于美联储声明，美国日期之后的首个中国日历日选报价，三份2024年下调声明已核对美东14:00发布、北京时间次日凌晨。黄金按自身报价日期计数，不把两资产日历强行相同。

收益为 `(终点收盘/基准收盘-1)*100%`。N为后续有效报价观测条数。非法价格、日期乱序、缺少前收盘、观察期不足、超过15个自然日的报价断层，收益为null而不是0。图前侧最多20条，基准归零。未独立验证完整历史交易日历，短缺口可能残留；日级对齐可能遗漏公告当日价格变化；Au9999夜盘归属未进一步分解，不能声称精确事件冲击估计。

## AI的角色及相对价值

使用用户提供的 `macro-event-candidate-pool` skill，离线完成宽筛分层、事实与解释区分、引用组织；候选JSON、可读清单与校验记录在evidence目录。主体、工具、方向和日期由确定性规则约束入选，后续涨跌不用于选案例；宏观环境与预期差不足时标注未知。

**本版不接在线模型API**。Luna进行初步资料准备，额度用尽后由Codex接手，离线编写逐类差异/传导假设。网页把预研片段与本次选中案例的确定性计算结果组装成报告，并明确说明无在线模型调用。按钮不伪装成实时大模型生成。AI的增量价值在阅读材料、提炼结构、揭示对照局限和辅助形成可修改研究记录；规则只负责可核验计算和准入。自定义材料没有自动AI提取和独立核实能力。

没有实测节省时间、用户准确率或收益提升。验证计划：用同一研究任务比较人工找例耗时；由研究者逐对评价候选相关性；记录引用可追溯率、用户修改位置与缺口处理。测试用的保存记录不当作真实用户成果。
